## ما هي منصة MADEL Studio Bridge؟

**MADEL Studio Bridge** هي منصة متقدمة ومحلية قائمة على بروتوكول [Model Context Protocol (MCP)](https://modelcontextprotocol.io)، تمنح وكلاء ومساعدي الذكاء الاصطناعي (مثل Antigravity و Claude Code و Codex و Cursor) القدرة على التحكم المباشر والآمن في برامج الإنتاج والتصميم والمونتاج على نظام ويندوز.

بدلاً من تشغيل أدوات منفصلة تستهلك مساحات هائلة وتتصادم على منافذ الشبكة، توفر منصة MADEL Studio Bridge **بوابة موحدة** تدعم مضاعف الأنابيب المسمّاة (Windows Named Pipe Multiplexer)، مما يتيح لخادم خلفي واحد خدمة عدة عملاء ذكاء اصطناعي بالتوازي دون أي تضارب.

## الحالة التشغيلية الحالية للمنصة

### ✅ المكونات العاملة والمختبرة حياً (Production Ready)
- **مثبت Windows المكتبي وبوابة المصادقة الإنسانية (P25 Integration):**
  - **مثبت تنفيذي أصلي عبر NSIS (`.exe`):** حزمة تثبيت مستقلة `MADEL Studio Bridge_0.11.0_x64-setup.exe` بحجم 2.32 MB تعمل بنمط المستخدم العادي (`currentUser`) دون طلب صلاحيات إدارية UAC.
  - **بوابة المصادقة الإنسانية (Action Approval Gate):** حماية معمارية لمنع عملاء الذكاء الاصطناعي من المصادقة الذاتية على الحذف والتصيير، باشتراط موافقة بشرية عبر لوحة التحكم مع تذاكر أمان مشفرة لمرة واحدة.
  - **حزم مستقل وفك ارتباط تام عن سورس `D:\MCP`:** تضمين الباك إند بالكامل داخل `resources/server/dist/` لضمان التشغيل في أي مسار أو حاسوب نظيف.
  - **معالج إعداد أولي تفاعلي من 7 خطوات:** تدفق إرشادي يبدأ تلقائياً عند أول تشغيل لفحص التوافقية والتطبيقات والعملاء بنمط قراءة فقط.
  - **شريط مهام الويندوز (System Tray):** تشغيل دائم في الخلفية وإخفاء النافذة دون إيقاف خوادم MCP.
- **Adobe After Effects (أدوات P24 للرسوم المتحركة والموشن جرافيكس والتصيير):**
  - 57 أداة MCP متخصصة (إجمالي 231 أداة على المنصة الإبداعية الموحدة ككل).
  - **التحكم بالكومبوزشن والمشاريع:** إنشاء المشاريع والكومبوزشن، ضبط الأبعاد والمعدلات الزمنية، تفعيل نافذة العرض، وفحص وإدارة أصول الميديا.
  - **توليد الطبقات والتايبوغرافي:** طبقات نصية إجرائية مع الألوان والأحجام (`ae_add_text_layer`)، طبقات لونية مصمتة (`ae_add_solid_layer`)، أشكال فيكتورية (`ae_add_shape`)، إعادة التسمية، التحكم بالإظهار والإخفاء، وتعديل نقاط البداية والنهاية على التايم لاين.
  - **التحريك والتحويلات المكانية:** إحداثيات ثنائية وثلاثية الأبعاد 2D/3D، نسب التكبير Scale، زوايا الدوران Rotation، ومنحنيات الشفافية Opacity.
  - **استيفاء المفاتيح وتنعيم الحركة:** تنعيم زمني احترافي (`KeyframeEase`)، أنماط الاستيفاء (خطي، بيزييه، إيقاف)، أتمتة حركات الأشكال وتأثيرات النصوص الجاهزة (`fade_in`, `slide_up`, `typewriter`).
  - **لوحة Essential Graphics وتصدير MOGRT:** تصدير قوالب الموشن جرافيكس للمونتاج المباشر (`ae_export_mogrt`).
  - **محرك التصيير الخلفي aerender.exe:** تصيير الكومبوزشن في الخلفية دون تجميد واجهة المستخدم، محمي بحارس الموافقة الإلزامية `approved: true`.
  - **الدقة الرياضية والزمنية:** حسابات دقيقة لـ 8 معدلات إطارات قياسية (23.976 إلى 60 FPS)، وأكواد الوقت SMPTE بنوعيها Drop-Frame (`;`) و Non-Drop-Frame (`:`)، وإحداثيات قياسية مطابقة لأبعاد المشهد.
  - **حراس الأمان الصارمة:** اشتراط تأكيد الحذف الصريح `confirm: true` لحذف الطبقات، وموافقة التصيير الصريحة `approved: true`.
- **Browser MCP Gateway (أدوات P23 لأتمتة المتصفحات وجمع المراجع البصرية):**
  - 27 أداة MCP متخصصة.
  - **محرك أتمتة كروميوم المباشر:** تحكم أصيل وفائق السرعة عبر بروتوكول Chrome DevTools Protocol (CDP) لمتصفحي Google Chrome و Microsoft Edge على ويندوز دون تنزيل حزم أو ملفات متصفحات إضافية.
  - **عزل تام للجلسات:** ملفات تعريف مؤقتة ومعزولة (`--user-data-dir`) على منافذ محلية ديناميكية، مع استحالة تسريب الكوكيز أو كلمات المرور أو سجلات التصفح الخاصة بالمستخدم.
  - **التقاط المراجع والصور عالية الدقة:** لقطات شاشة كاملة أو لجزء محدد من الصفحة (`browser_get_screenshot`) مع حفظ فوري في مساحات العمل الإبداعية.
  - **فحص المحتوى والتفاعل الحي:** البحث المتقدم في شجرة DOM، ملء النماذج النصية، اختيار القوائم المنسدلة، النقر بالماوس، وقراءة النصوص المرئية بأمان.
  - **التشخيص الهندسي وشبكة الاتصال:** رصد أخطاء الكونسول لحظياً، تسجيل طلبات الشبكة الفاشلة (HTTP 4xx/5xx)، قياس مؤشرات الأداء، واستخراج شجرة إمكانية الوصول (Accessibility AX Tree).
  - **الأمان الصارم وعزل العمليات:** قائمة بيضاء لعناوين URL (`http`, `https`، والملفات المحلية المصرح بها)، حماية العمليات التدميرية بطلب تأكيد صريح (`approved: true` لرفع الملفات)، وإنهاء حصري للعمليات التي أنشأتها المنصة (عدم إغلاق متصفح المستخدم الشخصي نهائياً).
- **Adobe Premiere Pro 2026 (أدوات P22 المتقدمة لمونتاج الفيديو والتايم لاين والسيكونس):**
  - 39 أداة MCP متخصصة (إجمالي 186 أداة في المنصة عبر كل التطبيقات الإبداعية).
  - **مونتاج التايم لاين والشرائح:** دقة متناهية عبر محرك التكات الصحيحة (254,016,000,000 تكة بالثانية)، إدراج المقاطع بنمطي الإدخال والاستبدال، والتحريك والقص والتشذيب، وحذف المقاطع مع إغلاق الفجوات وفرض تأكيد الحذف الصريح `confirm: true`.
  - **التحكم بالمسارات المتعددة (Multi-Track):** فحص مسارات الفيديو والصوت والتحكم بالقفل والكتم والسولو.
  - **إدارة السيكونس ومعدلات الإطارات:** إنشاء وتفعيل واستخراج الطول الزمني والـ SMPTE Timecode لثمانية معدلات إطارات قياسية (23.976 إلى 60 FPS) دون أي انحراف عشري.
  - **الوسائط والمجلدات (Bins):** استيراد الوسائط، فحص الأصول، إنشاء مجلدات Bins، ونقل وتنظيم العناصر.
  - **التصدير والإنتاج:** اكتشاف قوالب التصدير (`.epr`)، تصدير إطارات المعاينة PNG، وتصدير السيكونس مباشرة أو عبر طابور Media Encoder.
  - **أمان العمليات:** تنفيذ كافة التعديلات داخل معاملات UXP الذرية (`project.lockedAccess` و `project.executeTransaction`) لضمان خطوة تراجع Undo واحدة نظيفة لكل أداة.
- **Adobe Illustrator 2025 (أدوات P21 المتقدمة للفيكتور والـ Artboards وتصدير SVG):**
  - 38 أداة MCP متخصصة.
  - **الأشكال والمنحنيات الفيكتورية:** مستطيلات بحواف دائرية، دوائر وقطوع ناقصة، خطوط مستقيمة، منحنيات بيزييه حرة متعددة النقاط مع مقابض المماس في الدخول والخروج (`ai_create_path`)، والمسارات المركبة (`ai_create_compound_path`).
  - **إدارة مساحات العمل والـ Artboards:** إنشاء ديناميكي لعدة Artboards مع تحويل دقيق للإحداثيات الفيزيائية، وتغيير الحجم وإعادة التسمية والتبديل بينها.
  - **الطباعة والنصوص الاحترافية:** نصوص نقطية وحاويات نصوص محددة، وربط خطوط PostScript، وتحديد الأحجام ومحاذاة الفقرات الكاملة (يمين، يسار، وسط، وضبط كامل).
  - **التصدير والإنتاج عالي الدقة:** تصدير SVG قياسي (مع أنماط CSS inline أو style elements)، وتصدير PDF فيكتوري متوافق مع Acrobat 5–8، وتصدير صور نقطية PNG بدقة تصل إلى 300 PPI، والحفظ الأصلي بصيغة `.ai`.
  - **عزل تشغيلي ثنائي المسار:** مسار مستقل تماماً عبر Windows COM ExtendScript دون أي تضارب على المنافذ أو تعارض مع سيرفر الفوتوشوب (المنفذ 7897 / PID 15940).
- **Adobe Photoshop 2026 (عبر لوحة UXP BatchPlay وأدوات P20 الإبداعية المتقدمة):**
  - 38 أداة MCP متخصصة تتصل عبر WebSocket محلي آمن (`ws://127.0.0.1:7897`).
  - **الكائنات الذكية (Smart Objects):** تحويل غير مدمر، استعلام البيانات والخصائص، نسخ مستقل عبر `placedLayerMakeCopy`، استبدال المحتويات مع الحفاظ على الأبعاد والأنماط، ومزامنة الملفات المرتبطة.
  - **أنماط الطبقات (Layer Styles):** محرك تأثيرات احترافي معالج على كرت الشاشة (الظل الخارجي والداخلي، التوهج، الشطف والتجسيم، الحشوات المتدرجة والمتصلة، والحدود).
  - **التحديدات والأقنعة (Selections & Masks):** تحديدات هندسية مستطيلة ودائرية مع عمليات الدمج المنطقي الأربع، وتنعيم الحواف، وأقنعة الطبقات مع ضمانات تأكيد الحذف للحماية من الفقدان غير المقصود.
  - **تجهيز وتصدير الطباعة التجارية:** دعم كامل لمساحة ألوان الطباعة CMYK بدقة 300 DPI، وتصدير TIFF غير مضغوط أو بضغط LZW مع الحفاظ على ملفات تعريف الألوان ICC.
  - تأمين كامل للمخططات عبر **Zod 4.6.7** وسد الثغرات المعروفة.
- **Blender 4.x / 5.x LTS:**
  - أتمتة المجسمات ثلاثية الأبعاد والخامات والكاميرات والإضاءة والتصيير (Render) عبر جسر بايثون.
  - كاش مشترك ومعزول على قرص التخزين الإضافي (`D:\MCP\runtime\uv-cache`).
- **CapCut Desktop (نظام ويندوز):**
  - الفحص البرمجي التلقائي لمسودات المونتاج والتايم لاين (`draft_content.json`).
  - توليد الترجمات، وتطبيق حركة الكاميرا Ken-Burns، وإدارة مقاطع البروكسي.
- **بوابة التزامن والتحكم بالطلبات (بوابة P17):**
  - دعم تزامن متعدد العملاء عبر الأنبوب المسمّى (`\\.\pipe\brainferno-mcp-bridge`) وإدارة طوابير FIFO مع حماية من تضارب العمليات المودال.
- **المدير الموحد لعملاء الذكاء الاصطناعي (P18):**
  - دعم 17 عميل ذكاء اصطناعي (Claude, Codex, Antigravity, Cursor...) مع تعديل ذري آمن، ونسخ احتياطية تلقائية `.bak`.
- **تطبيق سطح المكتب الأصلي وشريط المهام (P19 & P19.1):**
  - تطبيق ويندوز مكتبي خفيف وسريع (`apps/desktop/`) مبني باستخدام Tauri v2 و Vue 3 و Pinia و Windows WebView2 مع شريط المهام (System Tray).

## دليل تشغيل نسخة المطور (Developer Build)

### 1. استنساخ المستودع
```bash
git clone https://github.com/Mahmoudmarktingiq/madel-studio-bridge.git
cd madel-studio-bridge
```

### 2. تثبيت الحزم والتبعيات
```bash
npm install
```

### 3. بناء المشروع من السورس
```bash
npm run build
```

### 4. تشغيل حزمة الاختبارات
```bash
npm test
```
*يتم تشغيل 13 فحص توافقية بالإضافة إلى اختبار بروتوكول MCP عبر Stdio.*

### 5. تشغيل الخادم
```bash
npm start
```

## نموذج الأمان والخصوصية

- **اتصال محلي حصري (Localhost Only):** كافة المنافذ مقيدة بـ `127.0.0.1`.
- **أدنى صلاحيات (Least Privilege):** يعمل الخادم في مساحة المستخدم دون الحاجة لصلاحيات المدير Administrator.
- **حظر السكربتات المجهولة افتراضياً:** المتغير `BRAINFERNO_MCP_ALLOW_RAW_SCRIPTS=0` يمنع تمرير نصوص برمجية عشوائية دون موافقة صريحة.
- **خلو تام من الثغرات الأمنية:** تم فحص المشروع عبر `npm audit` بنسبة 0 ثغرات.
