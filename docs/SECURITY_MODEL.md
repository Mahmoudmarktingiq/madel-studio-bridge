## 1. المبادئ الأمنية الصارمة للمنصة (Core Security Tenets)

تتبنى منصة **MADEL Studio Bridge** مبدأ الأمان الصارم عند التعطل (Fail-Closed Security Model) وترتكز على المبادئ الإلزامية التالية:

1. **المحلية أولاً (Local First):** كافة الاتصالات محصورة حصراً على قنوات الاسترجاع المحلي (Loopback `127.0.0.1` و `localhost`) وأنابيب ويندوز المسماة (Named Pipes).
2. **الحد الأدنى من الصلاحيات (Least Privilege):** لا تطلب المنصة إطلاقاً صلاحيات المسؤول (Administrator) وتعمل بصلاحيات المستخدم العادي (Standard User).
3. **حظر المشاركة عبر الشبكة افتراضياً (No Network Sharing by Default):** خادم HTTP المشترك معطل افتراضياً (`httpPort = 0`) لمنع أي وصول خارجي عبر الشبكة المحلية أو الإنترنت.
4. **حظر وضع السكربتات العشوائية (No Raw Scripts by Default):** المتغير `BRAINFERNO_MCP_ALLOW_RAW_SCRIPTS=0` مفعل دائماً لمنع وكلاء الذكاء الاصطناعي من حقن وتمرير أكواد عشوائية إلى محركات التطبيقات.
5. **حظر الوضع غير الآمن (No Insecure Mode):** المتغير `BRAINFERNO_MCP_BRIDGE_INSECURE=0` مفعل دائماً لفرض مصادقة التوكن اللحظي (Cryptographic Token Handshake).
6. **عدم المساس بحماية النظام (No Defender / Firewall Tampering):** لا يتم تعديل إعدادات Windows Defender، أو إنشاء استثناءات لجدار الحماية، أو تعطيل فحص الحزم.
7. **انعدام التتبع الخفي (Zero Hidden Telemetry):** لا تحتوي المنصة على أي تتبع أو إرسال بيانات تشخيصية خارجية.
8. **حجب الأسرار من السجلات (Secrets Redaction):** يتم حجب رموز المصادقة والتوكنات تلقائياً من كافة السجلات ومخرجات Stdio.
9. **حماية ملفات المستخدم الأصلية (User Document Protection):** لا يتم فتح أو تعديل أو إغلاق أي مستند يخص المستخدم إلا بطلب صريح ومحدد بالأرقام.
10. **عدم اعتبار النقل إلى D عزلاً أمنياً (Storage is Not a Sandbox):** نقل الملفات والتبعيات من C إلى D هو إجراء تنظيمي وتخزيني لتحرير مساحة النظام، ولا يُعتبر بديلاً عن آليات العزل الأمني وتدقيق الصلاحيات.

## 2. مصفوفة تقييم ومكافحة التهديدات (Threat Mitigation Matrix)

| التهديد المحتمل (Threat) | ناقل الهجوم (Attack Vector) | إجراء الحماية المطبق في MADEL Studio Bridge |
| :--- | :--- | :--- |
| **هجوم إعادة توجيه DNS (DNS Rebinding)** | صفحة ويب خبيثة تحاول الاتصال بـ `ws://127.0.0.1:7897` | فحص ترويسة `Host` بدقة ورفض أي ترويسة لا تطابق Loopback صراحة (`127.0.0.1` أو `localhost`). |
| **سرقة اتصال WebSocket من صفحات الويب** | هجوم Cross-Site WebSocket Hijacking عبر المتصفح | فحص ترويسة `Origin` ورفض أي اتصال يحمل Origin ويب خارجي أو `null`. |
| **حقن سكربتات خبيثة داخل Photoshop** | وكيل ذكاء اصطناعي يحاول تشغيل كود عشوائي | تعطيل أداة `ps_batch_play` الخام وتحديد الأوامر بالدوال المكتوبة مسبقاً والمفحوصة فقط. |
| **تنازع واستيلاء الجلسات المتعددة** | تشغيل عميلين MCP في نفس الوقت | استخدام أنبوب Windows Named Pipe محلي ومشفوع بالصلاحيات المحلية لجلسات المستخدم فقط. |
| **قراءة وقرصنة الحافظة (Clipboard Snooping)** | إضافة UXP تحاول استراق بيانات الحافظة | تم حذف صلاحية `clipboard` بالكامل من ملف `manifest.json`. |
| **تسريب بيانات المشاريع للخارج** | محاولة أداة خارجية إرسال المستندات عبر الإنترنت | تقييد نطاقات الشبكة في UXP وحصرها على خادم Loopback المحلي فقط. |
