# P3 · معالجة أمان بيئة MCP

10 نوفمبر 2026. راجعت تقارير P2 الخمسة، وطابقت تثبيت Adobe مع الملفات المنشورة والـlockfile، وفحصت Stitch محلياً قبل تجهيز المختبر.

| شرط القبول | النتيجة |
|---|---|
| تحديد سبب Zod | ثبت أن `3.25.76` اعتماد مباشر واعتماد لحزمة البروتوكول، وظهر تنبيه GitHub في تدقيق npm للأساس |
| اختبار الإصلاح في العزل | بُني المرشح على `4.6.7` داخل AppContainer غير مرفوع، وحُفظت نواتج البناء في `P3-sandbox\input\candidate` |
| وظائف الاختبار | نجح بناء الحزمتين، و13 اختبار انحدار، وتشغيل stdio مع 68 أداة متطابقة في الحقول الأساسية. اجتازت المصافحة فحصاً اصطناعياً في الذاكرة |
| Stitch | خمس ملفات JSON تحمل قيمتين حرفيتين، وتطابق مثبت داخل سجل Claude. لم يظهر تطابق في كائنات Git المفحوصة لمشروع casher. بقي الاعتماد الحي دون تغيير |
| العزل | ACL محمي، وبيئة عمليات مصغّرة، وملفات تعريف اصطناعية، وفحوص رفض وصول خارج الجذر وتشغيل subprocess. حجب AppContainer اتصال WebSocket على loopback |
| الإنتاج | طابقت SHA-256 قبل وبعد لـ30 ملفاً مرجعياً، تشمل إعدادات Claude وCodex وAntigravity وBlender وComfyUI، وملفات Adobe الأصلية ونسخة تدقيقه. لم تُعدّل تطبيقات أو مشاريع الإنتاج |
| التراجع | أرشيف مطابق لـnpm وبيانات lock محفوظة داخل `backup`، وخط أساس مستقل للرجوع إليه في المختبر |

## ما يبقى

- مرشح Adobe يزيل التنبيه من الشجرة التشغيلية المقاسة. واجهة التوافق `zod/v3` داخل الطرد لا تُقبل لمسارات تحقق جديدة، ونتيجة المختبر لا تثبت توافق UXP وCOM مع التطبيقات الحية.
- قيمة Stitch المطابقة للسجل تستلزم قرار تدوير ومعالجة للسجل والنسخ بعد موافقة صاحبها. تعذر تأكيد نطاق المشاركات البعيدة.
- أُوقف مسار Windows Sandbox قبل تشغيل MCP عندما ظهر رمز إداري للضيف. إثبات العزل هنا من AppContainer وفحوص Node. تبقى مصافحة WebSocket كاملة على مضيف اختبار منفصل خطوة قبول لاحقة.

**حالة المرحلة:** اكتمل نطاق معالجة P3 في المختبر. المرشح قابل للمراجعة ضمن P4 معزولة بعد الموافقة. نقل الإصلاح إلى الإنتاج يتطلب تحقق UXP/COM ومراجعة Stitch وموافقة منفصلة.
