# التدقيق التفصيلي لسلسلة أدوات الذكاء الاصطناعي

تاريخ الرصد 10 نوفمبر 2026، بتوقيت بغداد. النطاق هو الجهاز الحالي، والمسارات المحددة، وجذور المشاريع الموجودة ضمن 25 نطاقاً معروفاً في حالة Claude. فُحصت إعدادات الملفات والملفات التنفيذية وأدلة التشغيل المحلية. اقتصرت اختبارات الخدمة على الرصد وطلب حالة Blender من رابط Codex الموجود. لم يُفتح مشروع إبداعي أو يُرسل طلب إلى طابور توليد.

## معيار الحكم

| الحالة | الدليل المطلوب |
|---|---|
| يعمل ومتحقق | استجابة حية للوظيفة أو للإصدار، أو عملية حية متطابقة مع مهمة محددة |
| بدأ محلياً | عملية مرتبطة بالعميل أو مستمع مطابق، دون دليل مستقل على استجابة الأداة |
| مسجّل | تعريف إعداد صالح للقراءة، منفصل عن نجاح المصادقة أو الاتصال |
| مثبت أو موجود | بيانات تثبيت أو ثنائية أو حزمة أو مصدر متحقق، مع توضيح غياب اختبار التشغيل |
| تاريخي | سجل تشغيل أو تعديل سابق، منفصل عن حالة الجلسة الحالية |

## ما تثبته الأدلة

- **Codex Desktop** يعمل من حزمة WindowsApps رقم `26.1103.7773.0`، وملف CLI المرفق أعاد `0.167.0-alpha.3.2`. يظهر داخل جلسة Codex بسبب مسار موارد الحزمة الذي ورثته العملية. لم يظهر عند إعادة الاختبار في Windows PowerShell `5.1.26100.9818` بلا ملف تعريف وبمساري Machine وUser فقط. لم يُعثر على alias مطابق أو npm shim في المواقع المعتادة.
- **Antigravity** يعمل من `C:\Users\asus\AppData\Local\Programs\Antigravity\Antigravity.exe` بإصدار منتج `2.30.0`. بدأ `language_server.exe` خادمي Blender وChrome DevTools. لا يظهر `agy` مستقلاً في PATH. الرقم `44.9.1` من ملف `version` المرفق لا يمثل إصدار منتج Antigravity.
- **Blender** يعمل من مسار Blender 5.2. أعاد طلب الحالة من Codex `5.2.3 LTS` وملحق `1.8` وبروتوكول `15/15` وتليمترية معطلة. استمع Blender على `127.0.0.1:9876`، ورُصدت اتصالات تابعة لعمليات خوادم Codex. إعداد Claude يشير إلى الحزمة نفسها، وتعذر إثبات استجابة من جلسة Claude حية لأنها لم تكن ظاهرة في لقطة العمليات.
- **Claude Code** ثنائية مثبتة ببيانات إصدار `2.1.278.0`. يوجد Blender في النطاق الشخصي وStitch في مشروع `casher`. لا يظهر تثبيت Marketplace عادي مفعّل في مصادره المحلية، وتوجد مهارات شخصية ووكلاء مخصصون للمشاريع. التفاصيل في [جرد المهارات](EXISTING_SKILLS.md).
- **Adobe** التطبيقات الثلاثة مثبتة. توجد حزمة Brainferno MCP Bridge فعلية `0.3.4` مع اعتمادياتها، بلا تسجيل لدى الوكلاء في النطاقات المفحوصة وبلا عملية أو لوحة Brainferno ظاهرة. وجود نسخة اختبار لا يثبت توافق المضيف. أولوية المنع من التفعيل هي اعتماد Zod المتأثر وصلاحيات اللوحات. التفاصيل في [حالة Adobe](ADOBE_INTEGRATION_STATUS.md).
- **ComfyUI Desktop** إصدار `0.4.57` مع نواة `0.3.45` وملف تعريف CPU. ظهر بدء الخادم تاريخياً على `127.0.0.1:8000`، وكان التطبيق والخادم غير ظاهرين وقت الرصد. لم يظهر `comfy-mcp` في إعدادات الوكلاء المفحوصة.
- **CapCut CLI** إصدار مثبت `0.33.1` ويدخل إليه PowerShell عبر npm shim. فحص Node صياغة الملف التنفيذي، ووجد التدقيق سجلي تعديل محليين يحوي كل منهما 19 إدخالاً لخمس عمليات. ظهر اختلاف فعلي في أحجام نسختي الجدول الزمني. لم يُشغَّل CLI على المشروع أثناء التدقيق.
- **الأدوات الأساسية** أعادت Python `3.13.5` وNode.js `26.13.0` وFFmpeg `9.0.2` إصداراتها. ظهر Flutter وDart عبر `C:\flutter\bin`، واكتُشف `uv/uvx` عبر WinGet Links. تدقيق ميزات Flutter/Dart خارج النطاق.

## الأولويات

1. **P0 قبل التفعيل** حل اعتماديات Adobe ومراجعة صلاحيات UXP وCOM. اعزل بيانات اعتماد Stitch المكتوبة في JSON وراجع النسخ التاريخية، مع التدوير بعد الموافقة إذا اتسع نطاق الوصول إليها.
2. **P1** ثبّت إصدار حزمة Blender بعد التحقق، وحدد عميل الكتابة الواحد. أكّد أداة حالة من Claude وأخرى من Antigravity في جلسات صريحة.
3. **P1** تحقق من ComfyUI Desktop على منفذه الفعلي، واختبر MCP الرسمي على بيانات اصطناعية فقط بعد الموافقة.
4. **P1** حدّد الجدول المرجعي لنسخة CapCut معزولة، واختبر تشخيص الإصدارات قبل أي معالجة.
5. **P2** حدد الحاجة إلى CLI مستقل لـCodex أو Antigravity، وراجع الازدواجيات لتعيين مصدر مرجعي لكل مهارة أو وكيل.

## طريقة العمل وحدودها

قُرئت ملفات الإعدادات انتقائياً، وعُرضت أسماء الحقول والمضيفون فقط لمدخلات الاعتماد. فحص العمليات والمنافذ احتاج قراءة مضيف Windows خارج عزل عملية PowerShell. استُخدم Windows PowerShell 5.1 لإعادة إنتاج مشكلة PATH، وPowerShell 7.6.9 لتحليل الملفات. اختبار `codex --version` نجح مع تحذير عزل عن تعذر تنظيف مجلدات مؤقتة أو إنشاء alias داخلي. قارنت بصمات المحتوى محلياً، ولم أعد تشغيل اختبارات Adobe أو أتصل بخدمات Stitch أو أستخدم مفاتيحها. غياب اكتشاف ملف خارج الجذور المفحوصة أو غياب عملية من لقطة واحدة لهما حدود واضحة.
