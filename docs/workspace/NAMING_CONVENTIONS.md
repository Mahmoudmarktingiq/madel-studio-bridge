# MADEL Studio Bridge — معايير وقواعد التسمية القياسية (Naming Conventions)

**الإصدار:** 1.0.0 — MANDATORY STANDARD  

---

## 1. قواعد تسمية المجلدات الرئيسية (Top-Level Directories)

1. **الترقيم الإلزامي ثنائي الخانات:**  
   يجب أن تبدأ مجلدات البرامج والمشاريع الرئيسية بأرقام ثنائية الخانات متبوعة بشرطة (`-`):  
   `01-Projects`, `02-Blender`, `03-CapCut`, `04-Photoshop`, ..., `10-Aspire`, `11-Other-Apps`.
2. **تسلسل البرامج الجديدة:**  
   عند إضافة برامج تصميم أو تطبيقات جديدة مستقبلاً، يتم منحها الرقم التالي بالتسلسل (`12-...`, `13-...`) دون تعديل أرقام البرامج السابقة.
3. **حظر الطبقات الوسيطة:**  
   يمنع نهائياً استخدام أي مجلد وسيط مثل `Creative-Workspaces`؛ أسماء البرامج توضع مباشرة تحت الجذر.

---

## 2. قواعد تسمية مجلدات البراندات والمشاريع (Brand & Project Naming)

1. **اسم البراند (Brand Name):**
   - يُكتب بصيغة `PascalCase` أو `Hyphenated-PascalCase`.
   - أمثلة: `AlMawada-CNC`, `Loris`, `MADEL`.
   - لا يُنشأ مجلد البراند إلا عند وجود مشروع عمل فعلي.
2. **اسم المشروع (Project Name):**
   - يُكتب بصيغة واضحة تصف الهدف مع أرقام تسلسلية عند التكرار (`Hyphenated-PascalCase` أو `kebab-case`).
   - أمثلة: `CNC-Product-Ad`, `Raw-Edit-Commercial`, `Social-Design-01`.

---

## 3. قواعد تسمية المجلدات الداخلية للمشاريع الإبداعية (The 8 Creative Subdirectories)

يجب الالتزام الحرفي بالأسماء والأرقام التالية لكل مشروع إبداعي:
- `01-Source`: الملفات الخام، المراجع، مقاطع الفيديو الأصلية.
- `02-Assets`: الشعارات، الخطوط، الأصوات، الخامات، الأيقونات.
- `03-Project`: ملفات العمل الرئيسية القابلة للتحرير (`.blend`, `.psd`, `.prproj`, `.aep`, إلخ).
- `04-Previews`: صور المعاينة وإطارات المراجعة ولقطات الشاشة (`.png`, `.jpg`).
- `05-Exports`: المخرجات النهائية الجاهزة للتسليم (`.mp4`, `.png`, `.pdf`).
- `06-Reports`: تقارير المشروع وملفات Markdown التحليلية.
- `07-Errors`: سجلات الأخطاء والمشاكل التقنية والإصلاحات.
- `08-Backups`: النسخ الاحتياطية المؤرخة لنقاط الاستعادة.

---

## 4. قواعد تسمية ملفات التوثيق والبيانات (Documentation & Files)

1. **الملفات المرجعية الرئيسية (Core Markdown):**
   - تُكتب بالحروف الكبيرة بالكامل `UPPERCASE.md`:
     `AGENTS.md`, `CLAUDE.md`, `CODEX.md`, `PROJECT_INFO.md`, `PROJECT_PROGRESS.md`, `README.md`.
2. **الملفات البرمجية والأدوات:**
   - تُكتب بصيغة `kebab-case`: `generator.js`, `cleanup-uv-cache.ps1`, `verify-uv-migration.ps1`.
3. **النسخ الاحتياطية المؤرخة:**
   - تتبع صيغة التاريخ القياسي: `<filename>.<YYYYMMDD>.bak`.
