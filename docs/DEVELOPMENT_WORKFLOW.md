## 1. المبادئ الجوهرية الثابتة (Core Engineering Tenets)

1. **التنفيذ المتسلسل الصارم (Sequential Single-Phase Execution):**
   - تنفيذ مرحلة واحدة محددة فقط في كل دورة عمل (`One Phase at a Time`).
   - يُمنع منعاً باتاً تجميع عدة مراحل تنفيذية في طلب أو إجراء واحد.
   - يُمنع الانتقال التلقائي إلى المرحلة التالية قبل مراجعة واعتماد المرحلة الحالية من قبل المطور محمود عادل.

2. **دورة حياة التطوير الإلزامية لكل مرحلة:**
   ```
   IMPLEMENT ──► TEST ──► SECURITY REVIEW ──► COMMIT ──► PUSH ──► REPORT ──► STOP
   ```

3. **نطاق العمل الصارم (Strict Scoping):**
   - كل مرحلة لها Scope محدد ومعلن بوضوح.
   - لا يجوز التعديل على ملفات أو محولات تقع خارج نطاق المرحلة الحالية.

4. **الاختبارات الإلزامية (Mandatory Testing):**
   - كل تغيير برمجي أو إضافة وظيفية يجب أن يصاحبها اختبارات تحقق (`Unit / Integration / Smoke Tests`).
   - لا تُقبل أي مرحلة دون اجتياز اختبارات بروتوكول MCP والأنابيب المسمّاة.

5. **فحص الأمان والخصوصية الصارم (Zero Secrets Policy):**
   - يُمنع منعاً باتاً رفع أو تضمين أي مفاتيح API، أو كلمات مرور، أو رموز توثيق (Tokens).
   - يُمنع رفع المسارات الشخصية أو بيانات المستخدم المحلي (`Windows User Paths`).
   - يُمنع رفع ملفات المشاريع الإبداعية أو أصول البراندات التجارية (`.psd`, `.blend`, `.mp4`).

6. **إدارة النسخ التشغيلية وخطط الاسترجاع (Operational Stability & Rollback):**
   - المجلد التشغيلي المعتمد `01-Projects\Installed` محمي ولا يتم تحديثه إلا بعد اكتمال واختبار سورس المرحلة بنسبة 100%.
   - لا يتم استبدال أي نسخة تشغيلية مستقرة دون وجود خطة تراجع واضحة (`Rollback Plan`) ونسخة احتياطية.

## 2. مصفوفة خطوات كل مرحلة

| الخطوة | الإجراء الفني | شرط الانتقال |
| :---: | :--- | :--- |
| **1. IMPLEMENT** | كتابة وتعديل الكود ضمن النطاق الحصري للمرحلة | الالتزام بالمعايير المعمارية |
| **2. TEST** | تشغيل `npm test` والفحوصات التوافقية الشاملة | 0 أخطاء (100% Pass) |
| **3. SECURITY REVIEW** | فحص التبعيات (`npm audit`) ومسح الأسرار والملفات المستثناة | 0 ثغرات، 0 أسرار |
| **4. COMMIT** | توثيق التغييرات برسالة واضحة ترتبط بالمرحلة | فحص رسالة Git ونظافة الملفات |
| **5. PUSH** | الرفع الآمن إلى مستودع GitHub المصرح به | نجاح المزامنة مع الفرع `main` |
| **6. REPORT** | إعداد التقرير التوثيقي الهندسي المفصل | توثيق النتائج و Commit SHA |
| **7. STOP** | التوقف التام وانتظار مراجعة وتوجيهات المستخدم | عدم بدء أي مرحلة تالية تلقائياً |
